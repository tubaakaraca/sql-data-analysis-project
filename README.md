# SQL Veri Analizi Projesi

Bu projede PostgreSQL kullanarak veri analizi yapılmıştır.

## Kullanılan SQL Konuları
- SELECT
- JOIN
- GROUP BY
- HAVING
- Subqueries
- Aggregate Functions

## Proje Amacı
Veri seti üzerinde analiz yaparak anlamlı içgörüler elde etmek ve SQL sorgu becerilerini geliştirmek.

## Kullanılan Araçlar
- PostgreSQL
- DBeaver
